שילוב משוואות מקסוול, משוואות חומריות, ותנועת חלקיקים טעונים בתווך

מערכת אלקטרודינמית כללית בחומר

נשקול מערכת הכוללת:

  • חלקיקים טעונים (כגון אלקטרונים) עם קואורדינטות rᵢ(t)
  • שדות אלקטרומגנטיים בתוך חומר: E, B, D, H
  • מאפייני חומר: ε(r), μ(r), σ(r)
  • קיטוב ומגנוט: P, M

הלגראנז'יאן הכללי יכלול שלושה חלקים עיקריים:

𝓛 = 𝓛חלקיקים + 𝓛שדות + 𝓛אינטראקציה

לגראנז'יאן מפורש

𝓛 = ∑ᵢ [½mᵢvᵢ² - qᵢφ(rᵢ) + qᵢvᵢ·A(rᵢ)]
+ ½∫ [ε₀E² - (1/μ₀)B²] d³r
+ ∫ [P·E - M·B] d³r
+ 𝓛חומר(P, M, ∇P, ...)

כאשר:

  • φ, A - פוטנציאלים סקלרי ווקטורי
  • E = -∇φ - ∂A/∂t, B = ∇×A
  • P - וקטור הקיטוב (דיפול ליחידת נפח)
  • M - וקטור המגנוט
  • 𝓛חומר - לגראנז'יאן פנימי של החומר

משוואות מקסוול בחומר

מעקרון הפעולה δ∫𝓛 dt = 0 עבור וריאציות של הפוטנציאלים φ ו-A:

לגבי φ:

∇·D = ρחופשית

לגבי A:

∇×H - ∂D/∂t = Jחופשית

יחד עם המשוואות ההומוגניות:

∇·B = 0, ∇×E + ∂B/∂t = 0

כאשר השדות המקרוסקופיים מוגדרים:

D = ε₀E + P,    H = (1/μ₀)B - M

משוואות חומריות

מווריאציות על P ו-M נקבל את משוואות התגובה של החומר:

δ𝓛/δP = 0  →  P = ε₀χeE  (עבור חומר לינארי)
δ𝓛/δM = 0  →  M = χmH  (עבור חומר לינארי)

עבור חומרים לא-לינאריים, 𝓛חומר יכלול איברים מסדרים גבוהים יותר:

𝓛חומר = ½α1P² + ¼α2P⁴ + ... + איברי שיפוע

איברי השיפוע (כמו ∇P) מתאימים לתיאור תנודות בקיטוב (פולריטונים).

תנועת אלקטרון בחומר

משוואת התנועה של אלקטרון במערכת:

d/dt (∂𝓛/∂vᵢ) - ∂𝓛/∂rᵢ = 0

נותן את כוח לורנץ המורחב:

mᵢ dvᵢ/dt = qᵢ[E(rᵢ) + vᵢ×B(rᵢ)] + Fחומר

כאשר Fחומר כולל:

  • כוחות עקב שיפועי דיאלקטרי: F = -∇(p·E) עבור דיפול p
  • כוחות חיכוך/התנגדות פרופורציוניים ל-v
  • כוחות עקב אי-הומוגניות בחומר

דוגמה: אלקטרון בחומר דיאלקטרי

עבור אלקטרון בחומר עם קבוע דיאלקטרי ε(ω):

Fדיאלקטרי = (q²/2)∇[1/ε(r,ω)]

כוח זה מתאים לאפקט של "דחיפה" או "משיכה" לאזורים עם ε שונה.

יחסי חומר כלליים

סוג חומר יחס חומרי תרומה ל-𝓛
לינארי איזוטרופי D = εE, B = μH ½∫(εE² - (1/μ)B²)dV
אניזוטרופי Dᵢ = εᵢⱼEⱼ ½∫εᵢⱼEᵢEⱼ dV
דיאלקטרי לא-לינארי P = ε₀(χ⁽¹⁾E + χ⁽²⁾E² + ...) ∫(½αP² + ¼βP⁴)dV
מוליך J = σE איבר דיסיפציה ב-𝓛 (לא שמרני)
דיאלקטרי עם פיזור ε(ω) = ε₁(ω) + iε₂(ω) 𝓛 עם איברים מרוכבים/דיסיפאטיביים

לתיאור דיסיפציה (התנגדות, בליעה), ניתן להוסיף פונקציית דיסיפציה 𝓡:

d/dt (∂𝓛/∂˙q) - ∂𝓛/∂q = -∂𝓡/∂˙q

לדוגמה, עבור התנגדות לינארית: 𝓡 = ½γv².

פתרון לדוגמה: אלקטרון בגביש

נבחן אלקטרון בגביש עם פוטנציאל מחזורי V(r) ושדה אלקטרומגנטי:

𝓛 = ½mẋ² - V(x) - eφ(x,t) + eẋ·A(x,t)
+ ½∫[ε(x)E² - (1/μ₀)B²]d³r

כאשר ε(x) מחזורית עם סריג הגביש.

משוואת התנועה המתקבלת:

mẍ = -∇V(x) - e∇φ + e(∇A)·ẋ + eẋ×(∇×A)
+ (e²/2m)∇[A²] + כוחות דיאלקטריים

בגביע אפקטיבי, עם קירוב המסה האפקטיבית m*:

m*ẍ = e(E + ẋ×B) - (1/τ)m*ẋ

כאשר τ זמן הרפיה עקב פיזור.

חוקי שימור ומשפט נתר

מהסימטריות של הלגראנז'יאן, נגזרים חוקי שימור:

  • שימור אנרגיה מנדיבות בזמן
  • שימור תנע מנדיבות במרחב
  • שימור מטען מנדיבות גלובלית ב-φ

טנזור מאמץ-אנרגיה משולב:

Tμν = Tשדהμν + Tחומרμν + Tאינטראקציהμν

חוק שימור מטען (ממשיך להתקיים גם בחומר):

∂ρ/∂t + ∇·J = 0

שימור התנע: התנע הכולל של השדות + החומר + החלקיקים נשמר.
