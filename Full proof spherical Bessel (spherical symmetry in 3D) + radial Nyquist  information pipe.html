הוכחה מלאה: בסל כדורי (סימטריה כדורית ב־3D) + נייקוויסט רדיאלי + צינור מידע

המסמך הזה מציג את כל שלבי ההוכחה בצורה מסודרת: 1) הלמהולץ → ODE רדיאלי 2) הצבה → פתרון בסל־כדורי 3) סדירות ב־0 4) ספקטרום רדיאלי 3D 5) נייקוויסט רדיאלי 6) דגימה→כימות→קידוד→הצפנה

0) הגדרות ותחום הבעיה

מטרה נרצה להבין שדה \(u(\mathbf{x})\) ב־\(\mathbb{R}^3\) כאשר הוא סימטרי־כדורית, כלומר תלוי רק ב־\(r=\|\mathbf{x}\|\).
הנחה מרכזית סימטריה כדורית: \(u(\mathbf{x}) = g(r)\).
משוואה נשתמש במשוואת הלמהולץ (כוללת גלים הרמוניים): \[ \nabla^2 u + k^2 u = 0 \] כאשר \(k>0\) הוא “תדר מרחבי” (מספר גל).
הערה: למה דווקא הלמהולץ?
משוואת הלמהולץ מתקבלת מהפרדת זמן במשוואת הגלים \(\partial_t^2 u = c^2\nabla^2 u\) עבור פתרון הרמוני בזמן \(u(\mathbf{x},t)=\Re\{U(\mathbf{x})e^{-i\omega t}\}\), ואז \(U\) מקיים \(\nabla^2 U + (\omega/c)^2U=0\).

1) שלב ראשון: הלפלסיאן בשדה רדיאלי ב־3D

נתחיל מהידוע בלפלסיאן בקואורדינטות כדוריות \((r,\theta,\varphi)\): \[ \nabla^2 u = \frac{1}{r^2}\frac{\partial}{\partial r}\!\left(r^2 \frac{\partial u}{\partial r}\right) +\frac{1}{r^2\sin\theta}\frac{\partial}{\partial \theta}\!\left(\sin\theta\frac{\partial u}{\partial \theta}\right) +\frac{1}{r^2\sin^2\theta}\frac{\partial^2 u}{\partial \varphi^2}. \]
אבל אם \(u(\mathbf{x}) = g(r)\), אז אין תלות בזוויות, ולכן: \[ \frac{\partial u}{\partial \theta}=0,\qquad \frac{\partial u}{\partial \varphi}=0 \] ומתקבל: \[ \boxed{\nabla^2 u = \frac{1}{r^2}\frac{d}{dr}\!\left(r^2 \frac{dg}{dr}\right)}. \]
הוכחת ביניים קצרה (למי שרוצה)
מכיוון ש-\(u=g(r)\), כל האיברים הזוויתיים מתאפסים. נשאר רק האיבר הרדיאלי שהוא נגזרת של \(r^2 g'(r)\) חלקי \(r^2\).

2) שלב שני: הצבת סימטריה במשוואת הלמהולץ → ODE רדיאלי

מציבים \(u(\mathbf{x})=g(r)\) במשוואת הלמהולץ: \[ \nabla^2 u + k^2 u = 0 \] ומקבלים: \[ \frac{1}{r^2}\frac{d}{dr}\!\left(r^2 g'(r)\right) + k^2 g(r)=0. \] זהו ה־ODE הרדיאלי ב־3D.
משוואה רדיאלית (3D) \[ \boxed{ \frac{1}{r^2}\frac{d}{dr}\!\left(r^2 \frac{dg}{dr}\right) + k^2 g = 0. } \]
צורה מפורשת של ה־ODE
נפתח: \[ \frac{d}{dr}\left(r^2 g'(r)\right)=2r g'(r)+r^2 g''(r) \] ולכן: \[ g''(r) + \frac{2}{r}g'(r) + k^2 g(r)=0. \] זו צורה קלאסית של משוואת בסל־כדורי מסדר 0 (עוד רגע נראה זאת).

3) שלב שלישי: הצבה שמורידה את ה־ODE למשוואה פשוטה

הטריק הידוע ב־3D: נציב \[ g(r)=\frac{\psi(r)}{r}. \] נחשב נגזרות: \[ g'(r)=\frac{\psi'(r)}{r}-\frac{\psi(r)}{r^2}, \qquad g''(r)=\frac{\psi''(r)}{r}-\frac{2\psi'(r)}{r^2}+\frac{2\psi(r)}{r^3}. \]
נציב בצורת ה־ODE: \[ g'' + \frac{2}{r}g' + k^2 g = 0 \] נקבל: \[ \left(\frac{\psi''}{r}-\frac{2\psi'}{r^2}+\frac{2\psi}{r^3}\right) +\frac{2}{r}\left(\frac{\psi'}{r}-\frac{\psi}{r^2}\right) +k^2\left(\frac{\psi}{r}\right)=0. \]
כעת מבטלים איברים: \[ -\frac{2\psi'}{r^2}+\frac{2\psi}{r^3} +\frac{2\psi'}{r^2}-\frac{2\psi}{r^3} = 0 \] ולכן נשאר: \[ \frac{\psi''(r)}{r} + k^2\frac{\psi(r)}{r}=0 \] נכפיל ב־\(r\neq 0\): \[ \boxed{\psi''(r) + k^2 \psi(r)=0.} \]
תוצאה הבעיה הרדיאלית ב־3D שקולה למשוואת מתנד הרמוני פשוטה עבור \(\psi\).

4) שלב רביעי: פתרון מלא + תנאי סדירות במרכז \(r=0\)

משוואת \(\psi''+k^2\psi=0\) נותנת: \[ \psi(r)=A\sin(kr)+B\cos(kr). \] ולכן: \[ g(r)=\frac{\psi(r)}{r}=\frac{A\sin(kr)+B\cos(kr)}{r}. \]
כעת “תנאי פיזיקלי/גיאומטרי” טבעי: הפתרון צריך להיות חסום במרכז. נבדוק את הגבולות ב־\(r\to 0\): \[ \sin(kr)\sim kr \quad\Rightarrow\quad \frac{\sin(kr)}{r}\sim k \quad (\text{חסום}) \] אבל: \[ \cos(kr)\sim 1 \quad\Rightarrow\quad \frac{\cos(kr)}{r}\sim \frac{1}{r} \quad (\text{מתבדר}). \] לכן חייבים לבחור: \[ B=0. \]
פתרון רגיל במרכז \[ \boxed{g(r)=A\,\frac{\sin(kr)}{r}.} \]
זה שקול ל־פונקציית בסל כדורית מסדר \(0\): \[ j_0(kr)=\frac{\sin(kr)}{kr} \quad\Rightarrow\quad g(r)=C\,j_0(kr). \]

5) (אופציונלי) הכללה: אם יש תלות זוויתית → \(j_\ell\) ו־\(y_\ell\)

אם לא מניחים סימטריה מלאה, אלא הפרדת משתנים עם הרמוניות ספריות \(Y_{\ell m}\): \[ u(r,\theta,\varphi)=R_\ell(r)\,Y_{\ell m}(\theta,\varphi), \] אז מתקבל ה־ODE הרדיאלי: \[ \boxed{ \frac{1}{r^2}\frac{d}{dr}\!\left(r^2 \frac{dR_\ell}{dr}\right) +\left(k^2-\frac{\ell(\ell+1)}{r^2}\right)R_\ell=0.} \]
הפתרונות הם: \[ R_\ell(r)=A\,j_\ell(kr)+B\,y_\ell(kr), \] כאשר \(j_\ell\) רגיל ב־\(r=0\) ואילו \(y_\ell\) סינגולרי. במקרה שלנו \(\ell=0\) ולכן \(j_0(kr)=\sin(kr)/(kr)\).

6) שלב חמישי: “תדר רדיאלי” ב־3D (פורייה כדורי / Hankel מסדר 0)

עבור פונקציה רדיאלית \(u(\mathbf{x})=g(r)\), גם הטרנספורם המרחבי שלה \(\widehat{u}(\mathbf{k})\) יהיה רדיאלי: \(\widehat{u}(\mathbf{k})=G(k)\), \(k=\|\mathbf{k}\|\).
זוג טרנספורם רדיאלי 3D (צורה סטנדרטית שקולה ל־Fourier–Bessel) \[ g(r)=\frac{1}{2\pi^2}\int_{0}^{\infty} G(k)\,\frac{\sin(kr)}{kr}\,k^2\,dk, \] \[ G(k)=4\pi\int_{0}^{\infty} g(r)\,\frac{\sin(kr)}{kr}\,r^2\,dr. \]
מה המשמעות של \(G(k)\)?
\(G(k)\) הוא “הספקטרום הרדיאלי” של \(g(r)\) במרחב התדר (המרחב הדואלי). הגרעין \(\sin(kr)/(kr)\) הוא בדיוק \(j_0(kr)\), ולכן שוב מופיע בסל־כדורי.

7) שלב שישי: משפט נייקוויסט רדיאלי ב־3D (הוכחת רעיון)

הנחה השדה הרדיאלי פס־מוגבל: \(G(k)=0\) לכל \(k>k_{\max}\).
מסקנה דגימה רדיאלית \(r_n=n\Delta r\) מספיקה ללא aliasing אם: \[ \boxed{\Delta r \le \frac{\pi}{k_{\max}}.} \]
רעיון ההוכחה (שלב־אחר־שלב):
  1. מאחר ש-\(G(k)\) מתאפס מעל \(k_{\max}\), האינטגרל לשחזור נהיה: \[ g(r)=\frac{1}{2\pi^2}\int_{0}^{k_{\max}} G(k)\,\frac{\sin(kr)}{kr}\,k^2\,dk. \]
  2. כשדוגמים ב-\(r_n=n\Delta r\), אנחנו בעצם מכפילים את \(g(r)\) ב”מסרק דלתא”: \[ g_s(r)=\sum_{n\in\mathbb{Z}} g(n\Delta r)\,\delta(r-n\Delta r). \] במרחב התדר (במובן 1D עבור המשתנה \(r\) כציר דגימה), פעולת הדגימה מייצרת שכפולים מחזוריים של הספקטרום במרווח \(\Omega_s=\frac{2\pi}{\Delta r}\).
  3. תנאי “אין חפיפה” בין שכפולים הוא: \[ k_{\max} < \frac{\Omega_s}{2}=\frac{\pi}{\Delta r}. \] שזה שקול ל: \[ \Delta r < \frac{\pi}{k_{\max}}. \] (בגבול שוויון עובדים “על הסף”; בפועל לוקחים מרווח בטיחות.)
  4. כאשר אין חפיפה, ניתן לסנן (Low-pass) כדי להחזיר את \(G(k)\) המקורי, ואז להחזיר את \(g(r)\).
הערה חשובה (דיוק מתמטי)
ההצדקה המלאה מערבת התאמה בין “דגימה ב־r” לבין פירוק רדיאלי ב־3D. ההיגיון המרכזי נשאר: הצפיפות הרדיאלית חייבת להתאים ל־\(k_{\max}\) כדי לא לייצר aliasing לאורך \(r\).

8) צינור מידע מלא: דגימה → כימות → קידוד → הצפנה (עם הצדקה)

A) Sampling
בוחרים \(\Delta r\) כך ש: \[ \Delta r \le \frac{\pi}{k_{\max}} \] ואז אוספים: \[ s[n]=g(n\Delta r). \]
B) Quantization
בוחרים \(B\) ביטים, \(L=2^B\), טווח \([g_{\min},g_{\max}]\): \[ \Delta_q=\frac{g_{\max}-g_{\min}}{L-1},\quad q[n]=\text{round}\left(\frac{s[n]-g_{\min}}{\Delta_q}\right). \]
C) Encoding
בגלל שברדיאלי יש “רציפות”, עושים דלתא: \[ d[0]=q[0],\quad d[n]=q[n]-q[n-1]. \] ואז מקודדים חסום־אורך (Varint) אחרי ZigZag לדלתאות חתומות.
D) Encryption
מצפינים את ה־payload ב־AES-256-GCM: מקבלים nonce + ciphertext + tag. ה־GCM מספק גם אימות שלמות (authentication).
למה הסדר הזה נכון?
  • דגימה תלויה בפיזיקה/תדרים: אם לא עומדים בנייקוויסט—אין מה “לתקן” אחרי זה.
  • כימות הופך רציף לבדיד ומייצר שגיאת כימות מבוקרת (נשלטת ע״י \(B\)).
  • קידוד מנצל סטטיסטיקה (דלתאות קטנות) כדי לחסוך נפח.
  • הצפנה אחרונה: אם מצפינים לפני דחיסה—הנתונים נראים אקראיים ולא נדחסים.

9) תבנית JavaScript קצרה לכל שלב (כדי לחבר לפרויקט שלך)

זה לא “הדמו המלא” (שכבר נתתי לך קודם), אלא תמצית של השלבים עם שמות פונקציות. אפשר להעתיק לתוך פרויקט Node.js או Browser (WebCrypto בדפדפן). 
// 1) Sampling
const dr = Math.PI / kMax;              // Nyquist radial step
for (let n=0; n<N; n++){
  const r = n*dr;
  s[n] = g(r);                          // your radial field
}

// 2) Quantization (uniform)
const L = 1 << B;
const dq = (gmax - gmin) / (L-1);
q[n] = Math.round((s[n]-gmin)/dq);

// 3) Encoding (delta + zigzag + varint)
d[0] = q[0];
d[n] = q[n] - q[n-1];
zz = (d<<1) ^ (d>>31);                  // zigzag (int32)
bytes.push(...varintEncode(zz));

// 4) Encryption (AES-GCM, browser)
nonce = crypto.getRandomValues(new Uint8Array(12));
cipher = await crypto.subtle.encrypt({name:"AES-GCM", iv: nonce}, key, payload);

// 5) Decrypt + Decode + Reconstruct
plain = await crypto.subtle.decrypt({name:"AES-GCM", iv: nonce}, key, cipher);
q = decodeVarintsToQ(plain);
sHat[n] = gmin + q[n]*dq;
הערה: Node.js
בדפדפן יש WebCrypto מובנה. ב־Node.js מודרני יש crypto.webcrypto.subtle או שתשתמש במודול crypto עם AES-GCM. אם תרצה, אני אתן לך קובץ Node.js מלא תואם 1:1 לדמו.

סיכום

הראינו בצורה מלאה:
  1. איך סימטריה כדורית ב־3D הופכת את הלמהולץ ל־ODE רדיאלי.
  2. איך ההצבה \(g=\psi/r\) מורידה למשוואה \(\psi''+k^2\psi=0\).
  3. איך תנאי סדירות ב־0 נותן פתרון \(g(r)\propto \sin(kr)/r\), שהוא \(j_0\).
  4. איך הספקטרום הרדיאלי 3D משתמש בגרעין \(\sin(kr)/(kr)\).
  5. איך מתקבל תנאי נייקוויסט רדיאלי \(\Delta r \le \pi/k_{\max}\).
  6. איך בונים שרשרת תקשורת/אחסון: דגימה→כימות→קידוד→הצפנה.
אם תרצה, אני יכול לאחד את “הדמו המלא” (הקובץ עם גרף + AES-GCM + encode/decode) יחד עם ההוכחה הזאת בתוך קובץ HTML אחד ענק.
