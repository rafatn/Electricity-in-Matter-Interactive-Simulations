Δ-טעינה לאופניים חשמליים — שלדה סולארית + “הבדלים”

כל “הבדל” פיזיקלי Δ (מהירות/בלימה, מומנט דיווש, אור, טמפרטורה) → מומר לחשמל → מתאחד ב־DC Bus → נכנס לסוללה דרך מטען CC/CV וה־BMS.

רעיון המערכת (הכל ביחד)

Δ → P → DC BUS → CC/CV → BMS → Battery

מודל מתמטי קצר

P_in = P_regen + P_pedal + P_solar + P_thermo
I_est ≈ P_in / V_batt
I_chg = min(I_est, I_max)
P_chg = I_chg · V_batt
ΔE_batt(Wh) = P_chg · t(h)
ΔSOC(%) = 100 · ΔE_batt / E_batt

כדי שזה יהיה “אמיתי”: רגנרציה קיימת רק אם המנוע + הבקר תומכים. שלדה־סולארית עובדת הכי טוב כשהאופניים עומדים בשמש (פחות צל מהרוכב).
