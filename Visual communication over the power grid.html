תקשורת חזותית מעל רשת החשמל

כולל חישוב רוחב-פס מעשי להעברת וידאו

הנחות בסיס לחישוב

  • מתח רשת: 230V / 50Hz
  • תחום נשא מאושר: 1–30MHz
  • רוחב פס אפקטיבי: ~20MHz
  • שיטת מודולציה: OFDM + QAM
  • יחס רעש ממוצע (SNR): 20–30dB

חישוב קיבולת תאורטית

נוסחת שאנון

C = B × log₂(1 + SNR)

פרמטר ערך
רוחב פס (B) 20 MHz
SNR ≈ 100 (20dB)
log₂(1+SNR) ≈ 6.65
קיבולת תאורטית ~133 Mbps

⚠ בפועל נניח 50–60% יעילות בגלל רעש, FEC וסנכרון.

קיבולת מעשית: ≈ 65–80 Mbps

דרישות וידאו טיפוסיות

פורמט קידוד רוחב פס
720p @30fps H.265 2–4 Mbps
1080p @30fps H.265 4–8 Mbps

✔ המערכת יכולה להעביר:

  • מספר ערוצי 1080p במקביל
  • או ערוץ 4K אחד יציב

Latency (השהיה)

  • קידוד H.265 Low-Latency: ~10–20ms
  • מודולציה + קו: ~1–3ms
  • פענוח: ~10–20ms

Latency כולל: ≈ 25–40ms (טוב משידור IP רגיל)
