מערכת יחסותית עם קרינה כוכבית

נשקול מערכת יחסותית מלאה הכוללת:

  • חלקיקים טעונים יחסותיים (אלקטרונים, פרוטונים)
  • שדות אלקטרומגנטיים מלאים במרחב-זמן שטוח
  • קרינת שמש וירח כגלים אלקטרומגנטיים חיצוניים
  • חומרים עם תכונות אלקטרומגנטיות
  • מערכות ייחוס כוכביות (לא רק ארציות)

מערכת שמש-ירח-חלקיק

קרינה מהשמש והירח משפיעה על תנועת חלקיקים טעונים

לאגראנז'יאן יחסותי מלא

𝓛 = 𝓛חלקיק + 𝓛שדה + 𝓛חומר + 𝓛קרינה + 𝓛אינטראקציה

בסימון טנזורי 4-מימדי:

𝓛 = √(-g) [ -¼μ₀⁻¹ FμνFμν + 𝓛m(ψ, ∂ψ) ]
+ ∑i ∫ [-mᵢc² dτᵢ/dt + qᵢ uᵢ·A δ⁴(x - xᵢ)] dt

כאשר:

  • g = det(gμν) - דטרמיננטת המטריקה
  • Fμν = ∂μAν - ∂νAμ - טנזור השדה
  • uμ = dxμ/dτ - 4-מהירות
  • dτ = √(gμνdxμdxν) - זמן עצמי

קרינת שמש וירח כגלים אלקטרומגנטיים

קרינה מהשמש והירח מתוארת כגלים מישוריים יחסותיים:

Aשמשμ(x) = εשמשμ A₀(שמש) e^{i kα(שמש) xα}
Aירחμ(x) = εירחμ A₀(ירח) e^{i kα(ירח) xα}

עוצמת ההארה (Irradiance) נכנסת דרך המשרעת:

A₀(שמש) = √(2Iשמש/(ε₀c)) × 1/|k|
A₀(ירח) = √(2Iירח/(ε₀c)) × 1/|k|
גוף שמימי עוצמת ההארה (W/m²) אורך גל דומיננטי ווקטור גל k (בקרבת כדוה"א)
שמש 1361 (קבוע השמש) 500 nm (אור נראה) kשמש ≈ (ω/c, -ω/c, 0, 0)
ירח (מואר מלא) 0.001 - 0.01 500 nm (החזרה) kירח = kשמש + Δk(מיקום יחסי)
הערה: עוצמת קרינת הירח תלויה במופע הירח ומרחקו מכדור הארץ

מערכות ייחוס כוכביות

מטריקה במערכת ייחוס כוכבית:

ds² = gμνdxμdxν
= -c²(1 + 2Φ/c²)dt² + (1 - 2Φ/c²)(dx² + dy² + dz²)

כאשר Φ הוא הפוטנציאל הכבידתי הכולל של כל הגופים:

Φ = Φשמש + Φירח + Φארץ + Φכוכבי לכת

טרנספורמציית לורנץ למערכת ייחוס אחרת:

x'μ = Λμν xν
Λμν = δμν + ωμν
ωμν = -ωνμ (טנזור אנטי-סימטרי)

מהירות יחסית בין מערכות ייחוס:

vארץ-שמש ≈ 30 km/s
vירח-ארץ ≈ 1 km/s

משוואות תנועה יחסותיות

מעקרון הפעולה היחסותי δ∫𝓛 d⁴x = 0:

עבור חלקיקים:
d/dτ (m uμ) = q Fμν uν + fקרינהμ
עבור השדה:
∂μ Fμν = μ₀ Jν
Jν = Jחלקיקיםν + Jקיטובν + Jקרינהν

כוח הקרינה כולל:

fקרינהμ = σT [Fקרינהμα Fקרינהαν uν - (u·Fקרינה·Fקרינה·u)uμ/c²]

כאשר σT הוא חתך פיזור תומסון לאלקטרון.

לחץ קרינה יחסותי

לחץ קרינה מהשמש והירח בחומר:

Pקרינה = I/c × (1 + R - T) × cos²θ

בגבול יחסותי, עם גורם לורנץ γ:

Pקרינה, יחסותי = γ² × Pקרינה, ניוטוני
γ = 1/√(1 - v²/c²)

השפעת לחץ קרינה על אלקטרון:

dv/dt = (σT I)/(m c²) × (1 - v·ŝ/c) ŝ
- (σT I)/(m c²) × v/c

כאשר ŝ הוא וקטור יחידה לכיוון מקור הקרינה.

קרינת שמש יכולה להאיץ אלקטרונים למהירויות יחסותיות בחלל בין-פלנטרי!

אפקטים מתקדמים

1. אפקט דופלר יחסותי:

ω' = γ ω₀ (1 - v·ŝ/c)
λ' = λ₀ / [γ (1 - v·ŝ/c)]

2. אפקט אברציה של אור כוכבים:

tan(θ') = sin(θ) / [γ (cos(θ) - v/c)]

3. לחץ קרינה עם קיטוב חומר:

Fקרינה = (I/c) × [ε(ω) - 1]/[ε(ω) + 2] × ∇|E|²

4. אינטראקציה עם שדה כבידה כוכבי:

Rμν - ½gμνR = (8πG/c⁴) Tμν
Tμν = Tחומרμν + Tקרינהμν + Tאלקטרומגנטיμν

דוגמה: אלקטרון באטמוספירה

מערכת ייחוס: כדור הארץ הנע סביב השמש

לגראנז'יאן עבור אלקטרון באטמוספירה:

𝓛 = -mₑc²√(1 - v²/c²) - e(φ + v·A)
+ ½ε₀∫(E² - c²B²)dV + 𝓛קרינת שמש + 𝓛קרינת ירח

פתרון בקירוב:

v(t) = v₀e^{-t/τ} + (eE₀τ/m)[1 - e^{-t/τ}]
+ (σTI₀τ/mc)[1 - e^{-t/τ}] ŝ

כאשר τ הוא זמן הרפיה, ו-E₀ הוא שדה מקרוסקופי.
